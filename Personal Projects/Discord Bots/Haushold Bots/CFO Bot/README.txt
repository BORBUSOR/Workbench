This is a "Home CFO"

Using Plaid API keys, I was able to make a discord bot that will automatically determine where to allocate my paychecks to optimize saving, spending, and investing the money I earn. It works per person in a discord server so long as the bot is active. While the bot works fine, Plaid charges each time it is called to provide live information so this bot was not financially sustainable to use actively unfortunately. I coded the bot in Python and made a small web interface to allow any user to go link their accounts to the bot. After linking, the user just has to wait for the weekly "CFO Report" where the bot determines what to allocate where based off of the current amounts in your accounts and spending history (up to 30 days however I was not able to check the exact timeframe Plaid would show the bot). Everything is safe and locked behind files with basic but effective security measures, never allowing any person to interact with generated tokens and linking tokens to people using discord bot commands.
